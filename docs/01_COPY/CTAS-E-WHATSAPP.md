# CTAs e WhatsApp

## CTA principal

**Solicitar orçamento agora**

## Alternativas

- Fazer orçamento
- Pedir orçamento
- Falar com a MRS Resolve
- Enviar fotos pelo WhatsApp
- Consultar atendimento

## Regra

Usar um CTA principal consistente em todo o site. Evitar cinco frases diferentes competindo entre si.

## Formulário rápido antes do WhatsApp

Perguntas:

1. O que será pintado?  
   Casa / Apartamento / Comércio / Condomínio

2. Qual serviço?  
   Interna / Externa / Completa / Não sei ainda

3. Onde fica?  
   Lago Sul / Lago Norte / Asa Sul / Asa Norte / Noroeste / Sudoeste / Park Way / Jardim Botânico / Outra região

4. Fotos  
   Incentivar o envio de fotos no WhatsApp.
