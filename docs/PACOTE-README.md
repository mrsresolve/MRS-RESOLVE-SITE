# MRS Resolve — Pacote do Site

Este pacote reúne a direção aprovada para a primeira versão do site da MRS Resolve: copy, UX, identidade visual, SEO local e assets.

## Ordem recomendada de uso

1. Leia `01_COPY/COPY-SITE.md`.
2. Leia `02_INSTRUCOES/BRIEFING-DESIGN-UX.md`.
3. Para gerar o site com IA/Codex, use `02_INSTRUCOES/PROMPT-PARA-CODEX.md`.
4. Aplique as recomendações de `03_SEO/SEO-LOCAL.md` e `03_SEO/METADADOS.md`.
5. Use os logos em `04_ASSETS/logos/` e a prancha/referências em `04_ASSETS/referencias/`.

## Princípio central

A pessoa que chega ao site já está procurando pintura. O site não precisa convencê-la de que precisa pintar. Precisa demonstrar, em poucos segundos, que a MRS Resolve é uma opção rápida, organizada e profissional.

## Direção de linguagem

- títulos curtos e literais;
- evitar copy publicitária exagerada;
- foco em orçamento rápido;
- mostrar profissionalismo pelo design, processo e provas visuais;
- CTA principal sempre visível no mobile.

## Observação importante

As imagens de obras reais da MRS Resolve não estavam disponíveis neste pacote. As imagens incluídas são referências da identidade visual e aplicações de marca. Para publicação final, substituir placeholders do site por fotos reais de serviços e antes/depois.
